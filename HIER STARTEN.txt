Zur Not direkt diese Datei bearbeiten:
https://github.com/Fre-yin/DNST-Extended-Hotbar/edit/main/README.md

Der komplette neue Text zum Kopieren steht hier in:

Für README.en.md gibt es entsprechend:

Diese beiden TXT-Dateien sind nur Kopierhilfen. Auf GitHub heißen die
Zieldateien README.md und README.en.md, nicht .txt.

Wenn die gezielt geöffnete README schon neu ist, die Startseite aber noch
alt aussieht, schick einen Screenshot mit Dateiliste und ausgewähltem Zweig.
GitHub kann auch eine README unter .github bevorzugen; nicht blind löschen.
