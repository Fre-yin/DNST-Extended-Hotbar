DEIN GITHUB-UPDATE: EXTENDED HOTBAR 0.3.7 + HELFER 0.1.2

Alles ist lokal vorbereitet. Auf GitHub wurde von mir nichts geändert.
Deinen alten Release v0.3.6-r2 lässt du bestehen. Dieses Update bekommt
einen neuen Release mit dem Namen v0.3.7. Das Repository bleibt privat.

SCHRITT 1 – DIE DATEIEN AUF DER PROJEKTSEITE AKTUALISIEREN

1. Öffne dein Repository:
   https://github.com/Fre-yin/DNST-Extended-Hotbar

2. Klicke auf Add file → Upload files.

3. Öffne hier auf deinem PC den Ordner 1-Repository-Dateien.
   Drücke darin Strg+A und ziehe den gesamten INHALT in das Uploadfeld.
   Nicht den äußeren Ordner 1-Repository-Dateien selbst hochladen!

   Das sind 90 Dateien einschließlich Unterordnern. Sie ersetzen passende
   alte Dateien und ergänzen den Helfercode. Keine Dateien auf GitHub
   vorher löschen. Falls du dort zwischenzeitlich selbst etwas geändert
   hast, prüfe die betroffenen Dateien vor dem Bestätigen.

4. Als Commit-Text kannst du schreiben:
   Extended Hotbar 0.3.7 und Helfer 0.1.2 hinzufügen

   Wähle den bisherigen Hauptzweig main und klicke Commit changes.
   Ein Commit ist einfach ein gespeicherter Änderungsstand.

5. Auf der Projektseite sollten jetzt HotbarHelper sowie die aktualisierte
   deutsche und englische Beschreibung erscheinen. Ganz oben steht der
   neue Hinweis auf 0.3.7 und Spielbuild 25154317.

SCHRITT 2 – DEN FERTIGEN DOWNLOAD ALS NEUEN RELEASE ANLEGEN

1. Öffne Releases → Draft a new release / Create a new release.
   Der Downloadbereich ist hier:
   https://github.com/Fre-yin/DNST-Extended-Hotbar/releases

2. Wähle als neuen Tag:
   v0.3.7

   Falls angeboten, bestätige Create new tag. Ein Tag markiert den
   Quellcode-Stand für diese Version. Ziel / Target ist main mit deinem
   gerade gespeicherten Update, nicht der alte v0.3.6-r2-Stand.

3. Titel:
   Extended Hotbar 0.3.7 + Helper 0.1.2 – Test release

4. Öffne hier RELEASE-TEXT.txt. Kopiere den gesamten Inhalt in das große
   Beschreibungsfeld. Deutsch und Englisch sind bereits enthalten.
   Du musst nichts automatisch generieren lassen.

5. Öffne 2-Release-Downloads und ziehe ALLE VIER Dateien in das Feld
   für Release-Anhänge:
   - Extended-Hotbar-0.3.7.zip
   - Extended-Hotbar-0.3.7-mit-Testspielstand.zip
   - Extended-Hotbar-Helper-0.1.2-test.zip
   - SHA256SUMS.txt

   ZIPs nicht entpacken. Diese vier Dateien gehören an den Release,
   nicht über Upload files in den Quellcode.

6. Warte, bis alle vier Uploads fertig sind. Setze den Haken bei
   This is a pre-release. Es bleibt eine Testversion.

7. Du kannst zunächst Save draft wählen und alles in Ruhe ansehen.
   Wenn Titel, Text, Tag und Anhänge passen: Publish release.
   Das ändert nicht die private Sichtbarkeit deines Repositorys.
   Dafür brauchst du keine Einstellung unter Settings zu ändern.

ZUM SCHLUSS KURZ PRÜFEN

- Die neue Version heißt 0.3.7, nicht 0.3.6-r2.
- Unter Assets findest du drei selbst hochgeladene ZIPs und SHA256SUMS.txt.
- GitHub ergänzt außerdem Source code (zip) und Source code (tar.gz).
  Das ist normal. Diese beiden sind NICHT zum Installieren der Mod.
- Der Helfer enthält die Mod bereits. Wer ihn nutzt, braucht kein
  zusätzliches Mod-ZIP. Der Demo-Spielstand bleibt freiwillig.
- QA und Frieren sind absichtlich nicht in diesem Repository-Update.
- Die Spielstandskopie für die Original-Hotbar bleibt experimentell:
  ein vollständiger Laden/Speichern/Neuladen-Test im Spiel steht aus.

Du brauchst für diese Schritte weder ein Terminal noch Programmierkenntnisse.
Wenn dir eine Ansicht anders vorkommt, schick einfach einen Screenshot.
