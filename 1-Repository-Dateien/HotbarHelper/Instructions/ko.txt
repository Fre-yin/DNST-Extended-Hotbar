Extended Hotbar · 도우미 0.1.2 (테스트)

전체 패키지를 Mods가 아닌 별도 폴더에 압축 해제하세요. Extended-Hotbar-Helper.exe를 열고 게임 폴더를 확인한 뒤 두 가지 주요 작업 중 하나를 선택하세요. 다른 도구는 문제 해결 / 변경 취소에 있습니다. 변경하기 전에 게임을 종료하세요.

Extended Hotbar 설치 / 업데이트
인터넷 업데이트가 아닌 포함된 버전을 설치합니다. MelonLoader 0.7.3이 이미 설치되어 있어야 합니다. DS_B.0.4.19 / Steam 25154317 및 .NET Framework 4.8이 있는 Windows x64가 필요합니다.

기본 게임용 저장 복사본을 준비하고 Extended Hotbar 제거…
실험 기능: 스킬 배정 네 개와 아이템 슬롯 한 개를 가진 별도 캠페인을 만든 후 Hotbar를 비활성화합니다. 원본은 그대로 백업됩니다. 복사본의 로드, 저장, 다시 로드를 먼저 테스트하세요. 다른 모드는 유지됩니다. Ironmode 및 알 수 없는 형식은 거부합니다.

문제 해결 / 변경 취소 ▾
선택한 변경 취소
선택한 백업의 파일 및 키 변경을 취소합니다. 진행 상황은 되돌리지 않습니다. 변경된 파일이나 키는 자동 복원을 차단합니다.

잘못된 키 표시만 수정…
Alpha 표시 대신 Q/E/R/T, 아이템 Y, 캐릭터 1–0을 준비합니다. 저장 파일 변환이나 모드 제거는 하지 않습니다.

로드 감시를 위해 도우미를 열어 두세요. 게임을 종료하거나 시작하지 않습니다. Hotbar가 확실히 비활성이면 게임 종료 후 확인을 받고 기본 키를 제안합니다.

백업: %LOCALAPPDATA%\ExtendedHotbarHelper\Backups
변경 취소를 위해 보관하세요. 언어 선택은 도우미에만 적용됩니다. Windows 파일 선택 창은 Windows 언어를 사용합니다. 기술 진단은 원래 언어로 표시됩니다.

서명되지 않은 로컬 테스트 버전입니다. 패키지의 라이선스 안내를 보관하세요. 게임 그래픽에는 코드의 MIT 라이선스가 적용되지 않습니다.

이미 최신 상태입니다. 파일을 변경하거나 추가 백업을 만들지 않았습니다.

이 기록에는 취소할 변경이 없습니다. 복원하거나 삭제한 것이 없습니다.
