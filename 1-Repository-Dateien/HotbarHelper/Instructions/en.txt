Extended Hotbar · Helper 0.1.2 (test build)

Extract the entire package into its own folder, not Mods. Open Extended-Hotbar-Helper.exe and check the game folder. Choose one of the two main actions. Other tools are under troubleshooting / undo changes. Close the game before making changes.

Install / update Extended Hotbar
Install/update installs the included version, not an internet update. MelonLoader 0.7.3 must already be installed. Requires DS_B.0.4.19 / Steam 25154317 and Windows x64 with .NET Framework 4.8.

Prepare a save for the original game and uninstall Extended Hotbar…
EXPERIMENTAL: create a separate campaign copy with four skill bindings and one item slot, then disable Hotbar. The original is backed up and unchanged. Test loading, saving and reloading the COPY before relying on it. Other mods stay installed. Ironmode and unknown formats are refused.

Troubleshooting / undo changes ▾
Undo selected change
Select a backup and undo its file/key changes. Saves are not rolled back. Modified files or keys block automatic restoration.

Fix incorrect key labels only…
Fix Alpha labels by preparing Q/E/R/T, item Y and character keys 1–0. This does not convert a save or remove the mod.

Leave the helper open for load monitoring. It never closes or starts the game. If Hotbar is definitely inactive, original keys can be offered AFTER game exit, with your confirmation.
