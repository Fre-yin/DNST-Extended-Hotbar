**Mit Helfer:** Das gesamte Helfer-ZIP in einen eigenen Ordner entpacken, nicht in Mods. `Extended-Hotbar-Helper.exe` öffnen, Spielordner prüfen und **Extended Hotbar installieren / aktualisieren** wählen. Zusammenfassung prüfen und bestätigen. Danach das Spiel selbst über Steam starten. Der Helfer sichert ersetzte Hotbar-Dateien; andere Mods, Loader und Spielstände bleiben bei der Installation erhalten. Er installiert MelonLoader nicht und lädt keine Online-Updates. ## English

**Extended Hotbar 0.3.7 – for Dungeon Settlers DS_B.0.4.19 / Steam build 25154317**

Ten active skill slots, a separate basic attack and three item quickslots. The familiar character panel stays in place. Additional key bindings can be configured in the game's options.

### What's new

- **Mod 0.3.7:** Updated for game build 25154317. Slot behavior, frame artwork and the demo save are unchanged from 0.3.6.
- **Optional Helper 0.1.2:** Install/update without manually copying files. Two main actions, a dedicated removal selection dialog, reorganized help and controls in all ten game languages. Repeated language switching was fixed; unchanged installations do not create misleading undo entries.

### Which download do I need?

**Scroll down to Assets. Do not use Code → Download ZIP!** The automatic **Source code (zip/tar.gz)** downloads also provide source code, not an installable mod.

- **Extended-Hotbar-Helper-0.1.2-test.zip:** optional Windows helper. **Mod 0.3.7 is already included** – no separate mod ZIP needed.
- **Extended-Hotbar-0.3.7.zip:** manual mod package for your own campaign.
- **Extended-Hotbar-0.3.7-mit-Testspielstand.zip:** the same manual package plus the optional “10 Slots Testfile” demo save with assigned slots and extra items.

Do not install both manual packages together. **SHA256SUMS.txt** provides optional checksums for all three ZIPs. QA and Frieren are not included.

### Installation / update

Requires **Windows x64**, **Dungeon Settlers DS_B.0.4.19 / Steam build 25154317** and separately installed **MelonLoader 0.7.3**. The helper additionally requires **.NET Framework 4.8**. First back up your saves and close the game and all test copies.

**With the helper:** Extract the entire helper ZIP into its own folder, not into Mods. Open `Extended-Hotbar-Helper.exe`, check the game folder and choose **Install / update Extended Hotbar**. Review and confirm the summary. Start the game yourself through Steam afterwards. The helper backs up replaced hotbar files; installation preserves other mods, the loader and saves. It does not install MelonLoader or download online updates. Download a new helper package for a future version.

**Manually:** Extract one mod ZIP. Back up any existing `DungeonSettlers10Slots.dll` or legacy `DungeonSettlers12Slots.dll` outside Mods so multiple versions are not loaded. Copy the included **Mods** folder beside `DungeonSettlers.exe`, merging with an existing Mods folder – do not create Mods/Mods or delete other mods. Start the game. Initial MelonLoader setup may take longer; if the game closes afterwards, start it again.

The complete instructions are **READ FIRST - ENGLISH.txt** in each ZIP. Import the optional demo save separately using its own instructions; do not copy it into the game folder or overwrite your campaign. It was saved under **DS_B.0.4.17**, not newly played through on 0.4.19.

**Default keys:** skills **1–0**, items **Q/E/R**, character selection **Left Shift + 1–0**. Existing custom bindings are preserved.

### Return to the original hotbar: experimental feature

After your selection and confirmation, the helper's second main button creates a **separate campaign copy** and uninstalls Extended Hotbar. Your original is preserved. The copy keeps the first four skill assignments, basic attack and one item slot. Learned skills and inventory are not removed. Affected keys return to the original bindings; other mods, MelonLoader and unrelated settings remain.

**Save conversion is experimental.** Loading, saving and reloading the copy in an actual campaign have not yet been fully signed off. Use a test campaign first, not your only important save. Original and copy are not merged. Export supports 0.4.17 and 0.4.19; unknown formats and Ironmode are refused. A separate “Alpha” key-label repair in the help section does not convert a save.
