Troubleshooting / undo changes ▾
Undo selected change
Select a backup and undo its file/key changes. Saves are not rolled back. Modified files or keys block automatic restoration.

Fix incorrect key labels only…
Fix Alpha labels by preparing Q/E/R/T, item Y and character keys 1–0. This does not convert a save or remove the mod.

Leave the helper open for load monitoring. It never closes or starts the game. If Hotbar is definitely inactive, original keys can be offered AFTER game exit, with your confirmation.

Backups: %LOCALAPPDATA%\ExtendedHotbarHelper\Backups
Keep them for undo. Language selection only changes this helper. Windows file pickers use your Windows language. Technical diagnostics remain in their original language.

Local unsigned test build. Keep the package's license notices. Game artwork is not covered by the MIT code license.

Configure character keys…
Choose keys for characters 1–10 (0 = character 10).

With Hotbar skills on 1–0, choose Left Shift + 1–0.
Without the mod, bare 1–0 can be used if free.

Replaces both bindings only for character selection and additive selection. With bare digits, Shift + digits adds to selection; with the Shift preset, additive selection is unbound to prevent duplicate actions.

Mods and saves stay unchanged. If keys are already used, the helper lists them and asks separately to overwrite anyway. Without that confirmation, nothing changes. Cleared bindings and character keys are backed up and can be restored.

Close the game and test copies first.

Automatic online updates are planned for a future release. Until then, the helper uses update packages in your Downloads folder.

Place the helper ZIP and matching .zip.update.json together in Downloads. Choose “Update helper only” from the blue button. The new helper opens without installing the mod; the old EXE and shortcuts remain.
