Choose the matching, already installed loader. Never mix loaders in one copy.

Installation never changes keys. Extra slots start unbound; existing custom bindings are preserved.

Apply this profile explicitly?

Skills 1–10: 1–0
Characters 1–10: Left Shift + 1–0
Items 1–3: Q/E/R

Replaces both bindings for these actions. Additive character selection is unbound. Other conflicts are listed separately before writing. Close the game and all copies. Changes are backed up and can be undone.

The game folder is detected automatically. If several copies are found, choose the correct path. Manual selection remains available.

This helper works locally only. It does not contact the internet or download files. Obtain packages yourself from your chosen mod platform and place them in Downloads.

Only the MelonLoader package contains the optional demo save. The BepInEx package does not. No automatic import.

Install / update mod
Place the mod ZIP in Downloads, choose “Install / update mod” and check the game folder. Close the game before installing. Demo saves are not imported automatically.

Update helper only
Place the helper ZIP and matching .zip.update.json together in Downloads. Choose “Update helper only” from the blue button. The new helper opens without installing the mod; the old EXE and shortcuts remain.

Reset save to vanilla and uninstall Extended Hotbar
EXPERIMENTAL: create an additional manual save in the same campaign with four skill bindings and one item slot, then disable Hotbar. The original is backed up and unchanged. Test loading, saving and reloading the COPY before relying on it. Other mods stay installed. Ironmode and unknown formats are refused. Both saves share the campaign's autosaves. Keep the backup and do not overwrite your original save.

Troubleshooting / undo changes ▾
Undo selected change
Select a backup and undo its file/key changes. Saves are not rolled back. Modified files or keys block automatic restoration.

Fix incorrect key labels only…
Fix Alpha labels by preparing Q/E/R/T, item Y and character keys 1–0. This does not convert a save or remove the mod.

Leave the helper open for load monitoring. It never closes or starts the game. If Hotbar is definitely inactive, original keys can be offered AFTER game exit, with your confirmation.

Configure character keys…
Choose keys for characters 1–10 (0 = character 10).

With Hotbar skills on 1–0, choose Left Shift + 1–0.
Without the mod, bare 1–0 can be used if free.

Replaces both bindings only for character selection and additive selection. With bare digits, Shift + digits adds to selection; with the Shift preset, additive selection is unbound to prevent duplicate actions.

Mods and saves stay unchanged. If keys are already used, the helper lists them and asks separately to overwrite anyway. Without that confirmation, nothing changes. Cleared bindings and character keys are backed up and can be restored.
