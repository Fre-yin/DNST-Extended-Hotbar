이 게임 복사본의 로더
이미 설치된 로더를 선택하세요. 같은 복사본에서 로더를 혼용하지 마세요.

설치는 키를 변경하지 않습니다. 추가 슬롯은 미지정 상태이며 기존 설정은 유지됩니다.

이 프로필을 적용할까요?

스킬 1–10: 1–0
캐릭터 1–10: 왼쪽 Shift + 1–0
아이템 1–3: Q/E/R

이 동작들의 두 키 지정을 교체하고 추가 선택을 해제합니다. 다른 충돌은 기록 전에 별도로 표시됩니다. 게임과 모든 복사본을 닫으세요. 백업으로 되돌릴 수 있습니다.

게임 폴더를 자동으로 찾습니다. 여러 복사본이 있으면 올바른 경로를 선택하세요. 수동 선택도 가능합니다.

이 도우미는 로컬에서만 작동합니다. 인터넷에 연결하거나 파일을 다운로드하지 않습니다. 원하는 모드 배포 사이트에서 패키지를 직접 받아 다운로드 폴더에 넣으세요.

선택적 데모 저장은 MelonLoader 패키지에만 포함됩니다. BepInEx에는 없습니다. 자동으로 가져오지 않습니다.

모드 설치 / 업데이트
모드 ZIP을 다운로드 폴더에 놓고 ‘모드 설치 / 업데이트’를 선택한 뒤 게임 폴더를 확인하세요. 설치 전에 게임을 종료하세요. 데모 저장 파일은 자동으로 가져오지 않습니다.

도우미만 업데이트
도우미 ZIP과 해당 .zip.update.json을 다운로드 폴더에 함께 놓고 파란 버튼에서 ‘도우미만 업데이트’를 선택하세요. 모드를 설치하지 않고 새 도우미를 엽니다. 기존 EXE와 바로가기는 유지됩니다.

저장 파일을 바닐라로 되돌리고 Extended Hotbar 제거
실험 기능: 스킬 배정 네 개와 아이템 슬롯 한 개를 가진 같은 캠페인 내 추가 수동 저장 파일을 만든 후 Hotbar를 비활성화합니다. 원본은 그대로 백업됩니다. 복사본의 로드, 저장, 다시 로드를 먼저 테스트하세요. 다른 모드는 유지됩니다. Ironmode 및 알 수 없는 형식은 거부합니다. 두 저장 파일은 캠페인의 자동 저장 슬롯을 공유합니다. 백업을 보관하고 원본 저장 파일을 덮어쓰지 마세요.

문제 해결 / 변경 취소 ▾
선택한 변경 취소
선택한 백업의 파일 및 키 변경을 취소합니다. 진행 상황은 되돌리지 않습니다. 변경된 파일이나 키는 자동 복원을 차단합니다.

잘못된 키 표시만 수정…
Alpha 표시 대신 Q/E/R/T, 아이템 Y, 캐릭터 1–0을 준비합니다. 저장 파일 변환이나 모드 제거는 하지 않습니다.

로드 감시를 위해 도우미를 열어 두세요. 게임을 종료하거나 시작하지 않습니다. Hotbar가 확실히 비활성이면 게임 종료 후 확인을 받고 기본 키를 제안합니다.

백업: %LOCALAPPDATA%\ExtendedHotbarHelper\Backups
변경 취소를 위해 보관하세요. 언어 선택은 도우미에만 적용됩니다. Windows 파일 선택 창은 Windows 언어를 사용합니다. 기술 진단은 원래 언어로 표시됩니다.

서명되지 않은 로컬 테스트 버전입니다. 패키지의 라이선스 안내를 보관하세요. 게임 그래픽에는 코드의 MIT 라이선스가 적용되지 않습니다.

캐릭터 키 설정…
캐릭터 1–10의 키를 선택하세요(0 = 캐릭터 10).

Hotbar 스킬이 1–0에 지정되어 있으면 왼쪽 Shift + 1–0을 선택하세요.
모드가 없고 키가 비어 있으면 1–0을 사용할 수 있습니다.

캐릭터 선택과 추가 선택의 기본·보조 키만 교체합니다. 1–0 모드에서는 Shift + 숫자로 선택에 추가합니다. Shift 모드에서는 이중 동작을 막기 위해 추가 선택을 해제합니다.

모드와 저장 파일은 바꾸지 않습니다. 이미 사용 중인 키가 있으면 목록을 표시하고 덮어쓰기를 별도로 확인합니다. 확인하지 않으면 변경하지 않습니다. 해제된 키 할당과 캐릭터 키는 백업되며 복원할 수 있습니다.

먼저 게임과 테스트 복사본을 닫으세요.
